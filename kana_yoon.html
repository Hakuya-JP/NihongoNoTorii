Diptongales Hiragana (拗音 ようおn)

Los caracteres pequeños (ゃ ゅ ょ) combinados con la columna -i forman diptongos.

  • (shashin) → Fotografía (し + ゃ + し + ん)

    → しゃしん

  • (chotto) → Un poco (ち + ょ + っ + と)

    → ちょっと

  • (toukyou) → Tokio (と + う + き + ょ + う)

    → とうきょう

  • (jugyou) → Clase / Lección (じ + ゅ + ぎ + ょ + う)

    → じゅぎょう

  • (hyaku) → Cien (ひ + ゃ + く)

    → ひゃく
