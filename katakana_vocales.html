Vocales Katakana (ア イ ウ エ オ)

Practica las vocales principales del silabario Katakana para palabras extranjeras.

  • (aisukuri-mu) → Helado (Ice Cream)

    → アイスクリーム

  • (inkudo) → Tinta (Ink)

    → インク

  • (wukulele / ukurere) → Ukelele

    → ウクレレ

  • (ereki) → Guitarra eléctrica

    → エレキ

  • (orenji) → Naranja (Orange)

    → オレンジ
