⚙️ Guía: Cómo usar Mokuro con Nihongo no Torii

1
Instalar Mokuro

Abre tu terminal con Python 3.10+ instalado y ejecuta:

pip install mokuro
2
Procesar tu Manga con OCR

Coloca las imágenes de las páginas en una carpeta y ejecuta:

mokuro "C:\Ruta\A\Tu\Manga\Tomo1"

Mokuro generará un archivo .mokuro dentro de la carpeta.

3
Cargar en Nihongo no Torii

Haz clic en "Cargar Manga", selecciona el .cbz o las imágenes y el archivo .mokuro. ¡Listo para leer con Yomitan y minar a Anki!

⌨️ Atajos en el Visor de Manga

  • Ctrl + Scroll — Zoom in/out
  • 0 — Ajustar a pantalla  ·  1 — Escala 1:1
  • Clic en globo — Escuchar pronunciación o minar a Anki
