Sonidos Impuros Hiragana (が ざ だ ば ぱ)

Los comillas (゛ Dakuon) modifican el sonido básico a sonoro, y el círculo (゜ Handakuon) cambia H a P.

  • (gakkou) → Escuela (が + っ + こ + う)

    → がっこう

  • (zasshi) → Revista (ざ + っ + し)

    → ざっし

  • (daigaku) → Universidad (だ + い + が + く)

    → だいがく

  • (bangou) → Número (ば + ん + ご + う)

    → ばんごう

  • (pan) → Pan (ぱ + ん)

    → ぱん
